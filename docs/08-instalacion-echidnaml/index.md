# 8. INSTALACIÓN DE ECHIDNAML

**EchidnaML** permite trabajar **programación**, **robótica** e **inteligencia artificial** en un único entorno educativo. En este apartado encontrarás las versiones disponibles para GNU/Linux, Windows y macOS, junto con instrucciones paso a paso para instalar el programa en cada sistema operativo.

## ¿Y después de instalar EchidnaML?

Una vez instalado el programa ya puedes empezar a trabajar con las placas Echidna. Te recomendamos seguir este recorrido:

1. Conecta una placa Echidna al ordenador.
2. Explora los ejemplos que vienen incluidos en el submenú Archivo → Ejemplos y realiza modificaciones.
3. Para aprender más, consulta el resto de apartados de este manual.
4. Inspírate en los proyectos del [blog de Echidna Educación](https://echidna.es/).
